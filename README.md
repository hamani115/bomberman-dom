# Bomberman DOM

A multiplayer Bomberman game built with a custom JavaScript mini-framework project and a Go WebSocket server.

## Run the game

Open a terminal and go to the backend folder:

```bash
cd backend
```

Start the server:

```bash
go run .
```

Then open:

```text
http://localhost:8080
```

in your browser.

To test multiplayer, open the game in multiple browser windows or tabs.

## Controls

- `WASD` or arrow keys -> Move
- `Space` -> Place bomb
- Chat is available on the side of the game
